# 优化器评估数据集

本目录存放优化器评估所需的数据文件。

## 数据文件列表

### hotpot-500.json

HotpotQA 数据集的前 500 个样本，用于多跳问答任务的评估。

**格式**：
```json
[
  {
    "question": "问题文本",
    "answer": "答案",
    "context": [
      ["段落标题1", "段落内容1"],
      ["段落标题2", "段落内容2"]
    ]
  },
  ...
]
```

**获取方式**：
1. 从 Opik Optimizer 项目中复制
2. 或从 HotpotQA 官方数据集提取前 500 个样本

## 添加新数据集

要添加新的评估数据集：

1. 将数据文件放置到本目录
2. 在 `../` 目录下创建对应的数据集加载器（如 `gsm8k.py`）
3. 在 `../__init__.py` 中导出新的数据集函数
