# 登录密码错误排查指南

## 🔍 常见原因

1. **数据库未初始化** - 管理员账户不存在
2. **密码不匹配** - 数据库中的密码与配置文件不一致
3. **用户名错误** - 输入的用户名不正确
4. **环境变量冲突** - .env 文件中的配置被覆盖

## 📋 排查步骤

### 步骤 1: 检查后端服务是否运行

```bash
# 检查后端日志
# 应该能看到 API 启动信息
```

### 步骤 2: 确认配置文件

查看 `.env` 文件或 `settings.py` 中的配置：

```bash
cd diting/packages/diting-web/backend
cat .env | grep ADMIN
```

**默认值:**
- `ADMIN_USERNAME=admin`
- `ADMIN_PASSWORD=admin123`

### 步骤 3: 重新初始化管理员账户

**方法 1: 使用初始化脚本（推荐）**

```bash
cd diting/packages/diting-web/backend

# 重新初始化（会先检查是否存在）
uv run python -m diting_web.scripts.init_admin
```

**方法 2: 使用密码重置脚本（强制重置）**

```bash
cd diting/packages/diting-web/backend

# 强制重置密码为配置文件中的值
uv run python reset_admin_password.py
```

### 步骤 4: 直接使用 SQL 重置（如果上述方法都不行）

连接到 PostgreSQL 数据库：

```bash
# 使用 psql 连接
psql -U admin -d diting_web -h localhost

# 或使用 Docker
docker exec -it postgres psql -U admin -d diting_web
```

**查看管理员账户:**
```sql
SELECT id, username, is_active, created_at FROM admin_users;
```

**删除现有账户（然后重新初始化）:**
```sql
DELETE FROM admin_users WHERE username = 'admin';
```

然后退出 SQL 并运行：
```bash
uv run python -m diting_web.scripts.init_admin
```

### 步骤 5: 测试登录

**使用 curl 测试:**

```bash
curl -X POST http://localhost:8000/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin123"}'
```

**成功响应示例:**
```json
{
  "code": 200,
  "msg": "success",
  "data": {
    "access_token": "eyJhbGc...",
    "token_type": "bearer",
    "expires_in": 86400
  }
}
```

**失败响应示例:**
```json
{
  "detail": "Incorrect username or password"
}
```

## 🔧 快速修复方案

### 一键重置脚本

```bash
cd diting/packages/diting-web/backend

# 1. 删除数据库（重新开始）
docker-compose down -v
docker-compose up -d

# 2. 等待数据库启动（10秒）
sleep 10

# 3. 运行迁移
uv run alembic upgrade head

# 4. 初始化管理员
uv run python -m diting_web.scripts.init_admin

# 5. 测试登录
curl -X POST http://localhost:8000/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin123"}'
```

## 💡 常见错误及解决方案

### 错误 1: "Incorrect username or password"
**原因:** 用户名或密码不正确  
**解决:** 运行 `reset_admin_password.py` 重置密码

### 错误 2: "Connection refused"
**原因:** 后端服务未启动或端口不对  
**解决:** 
```bash
cd diting/packages/diting-web/backend
uv run uvicorn diting_web.main:app --reload
```

### 错误 3: "Database connection failed"
**原因:** PostgreSQL 未运行  
**解决:**
```bash
docker-compose up -d postgres
```

### 错误 4: CORS 错误
**原因:** 前端和后端不在同一域  
**解决:** 检查 `settings.py` 中的 `cors_origins` 配置
