## 技术实现要点

### 认证机制
- 使用 JWT Token 认证
- Token 存储在 localStorage
- Axios 请求拦截器自动添加 Authorization header
- 401 响应自动清除 token 并跳转登录

### 错误处理
- 所有 API 调用都包含 try-catch
- 统一的错误提示机制
- 响应拦截器处理未授权错误

### 加载状态
- 所有数据加载页面都有 loading 状态
- 显示友好的加载动画

### 数据刷新
- 操作完成后自动刷新列表
- 删除、上传等操作后更新数据

## 后端 API 路径
- Base URL: `/api/v1`
- 认证: `/auth/login`
- 数据集: `/datasets`
- 评估维度: `/metrics`
- 评估器: `/evaluators`
- 任务: `/tasks/*`
- 统计: `/statistics/dashboard`
