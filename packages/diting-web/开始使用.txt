====================================================================
  DiTing Web - Windows 本地调试快速指南
====================================================================

您好！这是为 Windows 用户准备的快速开始指南。

====================================================================
第一步：配置环境（首次运行）
====================================================================

1. 打开 PowerShell，进入后端目录：
   cd D:\pythonProject\aicoding\diting\diting\packages\diting-web\backend

2. 运行自动配置脚本：
   .\setup_local_env.ps1

3. 按提示输入：
   - 远程服务器 IP 地址
   - PostgreSQL 用户名/密码
   - Redis 密码（如果有）
   - MinIO Access Key/Secret Key
   - OpenAI API Key

4. 脚本会自动完成所有配置！

====================================================================
第二步：测试连接（可选但推荐）
====================================================================

uv run python test_remote_connection.py

如果显示"所有服务连接正常"，说明配置成功！

====================================================================
第三步：启动服务
====================================================================

需要打开 3 个 PowerShell 窗口：

【窗口 1 - 后端 API】
cd D:\pythonProject\aicoding\diting\diting\packages\diting-web\backend
uv run uvicorn diting_web.main:app --reload

【窗口 2 - Worker（处理异步任务）】
cd D:\pythonProject\aicoding\diting\diting\packages\diting-web\backend
.\run_worker.ps1

【窗口 3 - 前端（可选）】
cd D:\pythonProject\aicoding\diting\diting\packages\diting-web\frontend
pnpm install    # 首次运行需要
pnpm dev

====================================================================
第四步：访问应用
====================================================================

在浏览器中打开：

- API 文档：http://localhost:8000/docs
- 前端界面：http://localhost:5173
- 健康检查：http://localhost:8000/api/v1/healthz

默认账号：admin / admin123

====================================================================
常见问题
====================================================================

1. 脚本无法运行？
   以管理员身份运行 PowerShell：
   Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

2. 端口被占用？
   查看占用: netstat -ano | findstr "8000"
   终止进程: taskkill /PID <进程ID> /F

3. 无法连接远程服务？
   - 检查网络: Test-NetConnection -ComputerName <远程IP> -Port 5432
   - 确认防火墙已开放端口：5432, 6379, 9000
   - 查看详细配置指南: WINDOWS_本地调试指南.md

4. 需要更安全的连接？
   推荐使用 SSH 隧道（见 WINDOWS_本地调试指南.md）
