### 🔧 配置工具

#### `backend/setup_local_env.ps1`
- **用途**: 自动配置环境变量
- **使用**: `.\setup_local_env.ps1`
- **功能**: 
  - 交互式输入远程服务器信息
  - 自动生成 `.env` 文件
  - 可选自动安装依赖和初始化数据库

#### `backend/test_remote_connection.py`
- **用途**: 测试远程服务连接
- **使用**: `uv run python test_remote_connection.py`
- **功能**:
  - 测试 PostgreSQL、Redis、MinIO 连接
  - 显示详细的错误信息
  - 验证配置是否正确

#### `backend/run_worker.ps1`
- **用途**: 启动后台任务处理器
- **使用**: `.\run_worker.ps1`
- **说明**: 处理评估和合成任务

## 💡 使用建议

### 首次配置
```powershell
# 1. 阅读快速开始
type 开始使用.txt

# 2. 运行配置脚本
cd backend
.\setup_local_env.ps1

# 3. 测试连接
uv run python test_remote_connection.py
```

### 遇到问题
1. 查看 **`WINDOWS_本地调试指南.md`** 的故障排查部分
2. 运行测试脚本诊断: `uv run python test_remote_connection.py`
3. 检查 API 文档: http://localhost:8000/docs

### 深入学习
1. 阅读 **`backend/ARCHITECTURE.md`** 了解系统设计
2. 查看 **`docs/BACKEND_DESIGN.md`** 学习 API 设计
3. 运行测试: `pytest tests/`
